## Get AudioLens running

<Lead>
  AudioLens runs as a set of Docker Compose services: a CPU-only FastAPI
  control plane, one or more Celery workers that actually load models, Redis
  for sessions and job metadata, and a React frontend. This page gets the
  full stack running locally and walks through one analysis job.
</Lead>

<Badges items={["Open source", "MIT", "FastAPI · React 18"]} />

<Callout title="Model weights download on first use" tone="note">
  Env files are optional — sane defaults work without them. Model weights
  are not bundled; they download lazily the first time a job needs them. If
  you'd rather not wait mid-analysis, pre-warm them ahead of time (see
  below).
</Callout>

## Install and boot

<CodeTabs labels={["docker", "nvidia", "amd rocm", "macos mps"]}>

```bash
git clone https://github.com/ECHO-Lit/ECHO-LIT.git AudioLens
cd AudioLens
cp Backend/.env.example Backend/.env
cp Frontend/.env.example Frontend/.env
docker compose up --build
```

```bash
# NVIDIA
docker compose --profile gpu up --build \
  --scale worker-model-local=0 \
  redis api scheduler frontend worker-cpu worker-gpu
```

```bash
# AMD ROCm
docker compose --profile amd up --build \
  --scale worker-model-local=0 \
  redis api scheduler frontend worker-cpu worker-amd
```

```bash
# Apple Silicon (MPS) — Docker Desktop can't expose MPS, so the worker
# runs natively, outside Docker
cd Backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
STORAGE_LOCAL_ROOT=shared-storage ML_DEVICE=mps \
  celery -A app.core.celery_app:celery_app worker --queues=gpu-fast,gpu-large --concurrency=1
```

</CodeTabs>

<Callout title="Windows tip" tone="note">
  Keep the repo at a short path (e.g. `C:\dev\AudioLens`) — dataset paths are
  case-sensitive.
</Callout>

To pre-warm model weights instead of downloading them lazily on first job:

```bash
docker compose run --rm worker-model-local python3 -c \
  "from transformers import pipeline; pipeline('automatic-speech-recognition', model='openai/whisper-base')"
```

To tear the stack down: `docker compose down` (add `-v` to also wipe volumes).

## Run your first analysis

<Steps>
  <Step title="Open the frontend">
    Visit `http://localhost:8080`. A new anonymous session cookie is set
    automatically — there's no sign-up or login.
  </Step>
  <Step title="Pick a dataset or upload a clip">
    Start from a bundled dataset (see [/docs/datasets](/docs/datasets)) or
    upload your own `.wav`, `.mp3`, `.m4a`, or `.flac` file, up to 100 MB and
    10 minutes long.
  </Step>
  <Step title="Choose a model">
    Pick `whisper-base` (speech-to-text) or `wav2vec2` (emotion
    classification) from the model dropdown.
  </Step>
  <Step title="Launch an analysis">
    Start with a `prediction` job to see the model's raw output, then try
    `saliency` to see which parts of the waveform drove it. The UI polls the
    job until it completes.
  </Step>
  <Step title="Read the result">
    The result appears on the shared timeline. Open another panel — Attention
    or Embeddings, for example — and it stays in sync with the same
    datapoint.
  </Step>
</Steps>
